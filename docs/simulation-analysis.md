# Simulation Analysis

## Scenario

Deccan Harvest Foods Pvt. Ltd. is used as a fictional logistics scenario covering transportation, warehouse execution, inventory and customer service. The Week 5 exercise evaluates six months of simulated performance data and demonstrates how management can use KPI trends to identify improvement priorities.

## Illustrative Performance Changes

| Metric | Starting Level | Improved Level | Interpretation |
|---|---:|---:|---|
| OTIF | 89% | 96% | Better delivery reliability |
| Truck Utilization | 70.3% | 93.75% | Better consolidation and capacity use |
| Dock Turnaround | 110 min | 75 min | Faster warehouse/transport interface |
| Stock-out Rate | 7.5% | 2.4% | Improved availability |
| Freight Cost / Tonne | ₹2,150 | ₹1,825 | Lower transport cost intensity |
| Composite Score | 83.1 | 99.8 | Overall modeled performance improvement |

## Worked Example — Freight Cost

Assume annual shipment volume is 7,800 tonnes.

- Baseline freight cost = 7,800 × ₹2,150 = **₹1,67,70,000**
- Improved freight cost = 7,800 × ₹1,825 = **₹1,42,35,000**
- Illustrative annualized saving = **₹25,35,000**

This is a simulation result, not a claim of realized business savings.

## Worked Example — Truck Utilization

If a truck has 16 tonnes of capacity and an average baseline load is 11.25 tonnes:

`11.25 / 16 × 100 = 70.3%`

After better order consolidation, an average load of 15 tonnes gives:

`15 / 16 × 100 = 93.75%`

The improvement supports fewer partially loaded trips, but transport planning must still consider delivery windows, axle/weight limits and customer urgency.

## Operational Interpretation

The KPI set should be evaluated together. For example:

- High truck utilization should not be achieved by delaying urgent orders.
- Lower inventory may reduce working capital but can increase stock-outs if safety stock is inadequate.
- Faster dock processing can improve carrier turnaround but requires coordinated staging and documentation.
- Better OTIF can increase cost if it depends excessively on premium transport.

The value of the framework is therefore in balancing service, cost, inventory and execution rather than maximizing a single metric.
